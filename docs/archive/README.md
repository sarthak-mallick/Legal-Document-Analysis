# Archive

Frozen records of superseded bookkeeping. **Read for history; never update.**

## `week-1-execution.md` … `week-8-execution.md`

The 8-week build plan, closed 2026-03-26. Each file holds that week's Objective,
In Scope / Out of Scope, Live Task Status (task IDs like `W6-003`), an append-only
Session Log, and a Handoff Snapshot.

These were the live status documents under the old bookkeeping scheme. They are no
longer maintained and no week 9 file will be created — `docs/project-spec.md` still
describes a Week 9 scope, but that work is tracked as GitHub issues now.

**Current bookkeeping:** GitHub issues. See `docs/agents/issue-tracker.md` for the `gh`
conventions, `docs/agents/triage-labels.md` for labels, and `docs/agents/workflow.md`
for the execution workflow.

**Architectural decisions** that came out of this period live in `docs/adr/`, and the
debugging detail behind them in `docs/challenges.md`.
